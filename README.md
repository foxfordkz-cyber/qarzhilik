# QARZHЫ — қаржылық сауаттылық платформасы

**Қаржыны түсін. Саналы шешім қабылда.**

QARZHЫ — қаржылық білімді жүйелеу және практикалық қаржылық дағдыларды қалыптастыруға арналған цифрлық веб-орта.
Сайт қазақ және орыс тілдерінде жұмыс істейді.

## QARZHЫ Family · Отбасы бюджеті

Басты беттен «Отбасы бюджеті» жоспарлағышын ашыңыз немесе `/family` мекенжайына өтіңіз. Отбасының кірісін, жинақ мақсатын, мерзімін және айлық шығындарын енгізіңіз. Браузердегі ЖИ қазақша және орысша жазбаларды бес санатқа бөледі. Әр ұсынысты қолмен түзетуге болады. Жоспар айлық жарна мен бос қалдықты теңгемен көрсетеді.

Node.js 24 көмегімен `npm run dev:local` командасын орындаңыз да, [жергілікті сайтты](http://localhost:8787/family) ашыңыз. Интернетсіз жұмыс істеу үшін [HTML нұсқасын](outputs/ITFEST-Family-2026/QARZHY-Family.html) жүктеп, браузерде ашыңыз. [Модельдің тексеру нәтижелерін](outputs/ITFEST-Family-2026/model-evaluation.json) `npm run eval:family` командасымен қайта алуға болады.

## QARZHЫ Guide · Жеке оқу тақырыбын таңдау

Басты беттен «ЖИ көмегімен сабақ таңдау» тармағын ашыңыз немесе `/guide` мекенжайына өтіңіз. Студент өз жағдайын сипаттайды, браузердегі модель төрт тақырыптың бірін таңдайды, содан кейін студент жаттығу орындап, шешімін көреді. Модель сенімсіз жағдайда сұрақты нақтылауды ұсынады. Тіркелу мен API кілті қажет емес.

Жергілікті нұсқа: Node.js 24-пен `npm run dev:local` командасын орындап, `http://localhost:8787/guide` бетін ашыңыз. Бақылау сұрақтары мен нақты жауаптарды `npm run eval:guide` арқылы қайта тексеруге болады. Интернетсіз жұмыс істеу үшін [Guide HTML нұсқасын](outputs/ITFEST-2026/QARZHY-Guide.html) жүктеп алыңыз.

## Бөлімдер

- **Басты бет** — платформа туралы қысқаша ақпарат.
- **Қаржыны үйрену** — екі оқу бағыты: «Өмірге қажетті қаржы» және «Кәсіби қаржы» (18 тақырып, конспект, тест, MOOC бейнесабақтары).
- **Қаржы әлемі** — 8 банктің депозиттері мен несиелері, банктердің валюта бағамдары (тікелей), Отбасы банктің тұрғын үй бағдарламалары, калькуляторлар.
- **QARZHЫ туралы** — жоба және жоба құрастырушылары.
- **Бастау** — тіркелу, кіру, курсқа жазылу және жеке кабинет (прогресс, тест нәтижелері).

## Технологиялар

- HTML, CSS, JavaScript (фреймворксыз)
- [Cloudflare Workers](https://developers.cloudflare.com/workers/) — сайт пен API
- [Cloudflare D1](https://developers.cloudflare.com/d1/) — пайдаланушылар мен прогресс базасы
- ҚР Ұлттық Банкінің ресми бағамдары және банктердің ашық бағам виджеттері

## Құрылымы

```
public/           сайт беттері, стильдер, скрипттер, суреттер
  data/           сабақтар (life, pro), банктер, Отбасы банк бағдарламалары (*.ru.json — орысша)
  js/i18n-ru.js   орысша аударма
src/worker.js     API: тіркелу, кіру, прогресс, бағамдар
src/fx.js         банктердің валюта бағамдары
migrations/       D1 базасының кестелері
```

## Іске қосу

```bash
npm install
npm run db:migrate:local   # жергілікті база
npm run dev                # http://localhost:8787
```

Cloudflare-ға жариялау:

```bash
npm run db:migrate   # бір рет — серверлік база
npm run deploy
```
