# QARZHЫ — қаржылық сауаттылық платформасы

**Қаржыны түсін. Саналы шешім қабылда.**

QARZHЫ — қаржылық білімді жүйелеу және практикалық қаржылық дағдыларды қалыптастыруға арналған цифрлық веб-орта.
Сайт қазақ және орыс тілдерінде жұмыс істейді.

## Бөлімдер

- **Басты бет** — несие төлемі мен депозит кірісін есептеу, екі нұсқаны салыстыру және ЖИ көмегімен сабақ таңдау.
- **Қаржыны үйрену** — екі оқу бағыты: «Өмірге қажетті қаржы» және «Кәсіби қаржы» (18 тақырып, конспект, тест, MOOC бейнесабақтары).
- **Қаржы әлемі** — 8 банктің депозиттері мен несиелері, дереккөз қолжетімді болғанда валюта бағамдары, Отбасы банктің тұрғын үй бағдарламалары, калькуляторлар.
- **QARZHЫ туралы** — жоба және жоба құрастырушылары.
- **Бастау** — тіркелу, кіру, курсқа жазылу және жеке кабинет (прогресс, тест нәтижелері).

## QARZHЫ Guide · Жеке оқу тақырыбын таңдау

Басты беттен «ЖИ көмегімен сабақ таңдау» тармағын ашыңыз немесе `/guide` мекенжайына өтіңіз. Студент өз жағдайын сипаттайды, браузердегі модель жеке немесе кәсіби қаржы бойынша алты тақырыптың бірін ұсынады, содан кейін студент жаттығу орындап, шешімін көреді. Модель сенімсіз жағдайда сұрақты нақтылауды ұсынады. Тіркелу мен API кілті қажет емес.

Жергілікті нұсқаны іске қосу үшін Node.js 24-пен `npm run dev:local` командасын орындап, `http://localhost:8787/guide` бетін ашыңыз. Guide 1.1 моделі [56 синтетикалық бақылау сұрағының](outputs/ITFEST-2026/model-evaluation.json) 49-ына күтілген жауап берді. Нәтижені `npm run eval:guide` арқылы қайта тексеруге болады. Интернетсіз жұмыс істеу үшін [Guide HTML нұсқасын](outputs/ITFEST-2026/QARZHY-Guide.html) жүктеп алыңыз.

## QARZHЫ Family · Отбасы бюджеті

Мәзірдегі жеке «Отбасы бюджеті» қойындысын ашыңыз немесе `/family` мекенжайына өтіңіз. Отбасының кірісін, жинақ мақсатын, мерзімін және айлық шығындарын енгізіңіз. Браузердегі ЖИ қазақша және орысша жазбаларды бес санатқа бөледі. Әр ұсынысты қолмен түзетуге болады. Жоспар айлық жарна мен бос қалдықты теңгемен көрсетеді.

Node.js 24 көмегімен `npm run dev:local` командасын орындаңыз да, [жергілікті сайтты](http://localhost:8787/family) ашыңыз. Интернетсіз жұмыс істеу үшін [HTML нұсқасын](outputs/ITFEST-Family-2026/QARZHY-Family.html) жүктеп, браузерде ашыңыз. [Модельдің тексеру нәтижелерін](outputs/ITFEST-Family-2026/model-evaluation.json) `npm run eval:family` командасымен қайта алуға болады.

## Academy және Flutter пилоты

Жаңа курс кабинеті, оқытушыға арналған рұқсат беру, серверде тексерілетін тесттер және Flutter қолданбасы қосылды.
Жергілікті іске қосу, демонстрация және шектеулер: [PILOT.md](PILOT.md).
Node.js арқылы VPS нұсқасы Cloudflare-сыз жұмыс істейді: `npm run dev:local`.

🌐 Сайт: https://qarzhy.zerdeliportald.workers.dev

## Технологиялар

- HTML, CSS, JavaScript (фреймворксыз)
- [Cloudflare Workers](https://developers.cloudflare.com/workers/) — сайт пен API
- [Cloudflare D1](https://developers.cloudflare.com/d1/) — пайдаланушылар мен прогресс базасы
- ҚР Ұлттық Банкінің ресми бағамдары және банктердің ашық бағам виджеттері

## Құрылымы

```
public/           сайт беттері, стильдер, скрипттер, суреттер
  data/           сабақтар (life, pro), банктер, Отбасы банк бағдарламалары (*.ru.json — орысша)
  js/i18n-ru.js   орысша аударма
src/worker.js     API: тіркелу, кіру, прогресс, бағамдар
src/fx.js         банктердің валюта бағамдары
migrations/       D1 базасының кестелері
```

## Іске қосу

```bash
npm install
npm run db:migrate:local   # жергілікті база
npm run dev                # http://localhost:8787
```

Cloudflare-ға жариялау:

```bash
npm run db:migrate   # бір рет — серверлік база
npm run deploy
```
